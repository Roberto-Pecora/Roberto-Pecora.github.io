Vol. I — 5 studies

LLM Post-Training & RLHF Research

Controlled experimental studies of post-training methods for modern instruction-tuned language models, including supervised fine-tuning, preference optimisation, and reinforcement learning from verifiable and human-derived rewards. Each study isolates a single variable and reports uncertainty using bootstrap confidence intervals or paired statistical tests instead of single-run point estimates.

§1

Financial LLM post-training: SFT → DPO on Qwen3-4B

qwen3-financial-sft-unsloth-dpo

Base instruct models handle numeric financial questions poorly when the answer has to be grounded in a real filing rather than recalled. This project trains a small open model on that skill directly, then measures whether preference optimisation on top of it helps or quietly trades one capability for another.

Rank-16 QLoRA adapters on 4-bit Qwen3-4B: one epoch of supervised fine-tuning on TAT-QA, followed by DPO (β=0.1) on preference pairs. Each rejected answer is a shape-matched gold answer pulled from a different question, rather than a single constant rejection, forcing the model to distinguish correctness from surface plausibility.

Aggregate accuracy fell from 19.5% (base) to 14.1% (DPO) across 662 evaluation examples — but the per-answer-type breakdown shows this is a real tradeoff, not noise. Arithmetic accuracy rose 27× (0.36% → 9.96%) and multi-span accuracy also improved (23.5% → 27.9%), while count questions regressed sharply (35.0% → 10.0%) and extractive span only partly recovered from the SFT dip.

§2

GRPO vs. SFT on verifiable math reward

grpo-math-reasoning

On math problems where correctness is mechanically decidable, this study tests whether learning from a checkable reward beats imitating labelled examples. Both methods are trained on a single base model, rather than compared across published numbers from different setups.

Rank-32 QLoRA on Qwen2.5-1.5B, trained with GRPO against a stacked reward (format + correctness) rather than correctness alone. A 1.5B model rarely gets the exact answer right early in training, so a correctness-only reward gives no learning signal until it does.

GRPO reached 70.8% vs. SFT's 60.9%, a 9.9-point gain significant at p<4e-4. It also regressed 43 problems SFT had already solved even while fixing 80 others, a real cost the headline number obscures.

§3

Policy gradients from scratch: REINFORCE → GRPO

policy-gradient-from-scratch

Every RLHF-family algorithm shares one core idea, obscured by the different names and frameworks each is usually taught through. This project makes that idea visible by implementing five of them from scratch, with no RL library standing between the equations and the code.

A digit-sum toy task mirrors a GSM8K-style verifier: reward is 1.0 only if the generated digits sum to a target, with several correct sequences per target so the policy has genuine exploration to do. All five algorithms differ only in how the advantage term is computed, making each one's marginal contribution directly measurable against the others.

Accuracy rose monotonically with the sophistication of the advantage estimator: REINFORCE reached 49.9%, PPO 81.0%, and RLOO 98.2% on the same task and base model.

§4

Reproducing RLOO vs. PPO with Claude as judge

rloo-vs-ppo-rlhf

Published RLHF comparisons are usually judged by a single model, which raises the question of how much of the result is the training method versus the judge's particular preferences. This study reruns a published comparison on the original checkpoints, swapping the original GPT-4 judge for Claude.

Slot assignment, which summary the judge sees as A vs. B, is keyed deterministically by seed and example ID, controlling for position bias without needing to persist any extra state across runs.

The method ranking held under the new judge: PPO led at a 47.0% win rate, RLOO at 39.7%, both well above the SFT baseline's 15.3%. However, 93.3% of RLOO completions ended in ! or ?, a stylistic confound the win-rate gap alone would have completely hidden.

§5

SFT vs. DPO on a minimal grid-walk grammar

sft-vs-dpo-grid-walk

Imitating a distribution (SFT) and optimising an objective (DPO) are easy to conflate in practice. This teaching example separates the two on a grid-walk small enough to reason about by hand, rebuilding an existing but broken demonstration into something reliable.

A no-immediate-reversal move grammar generates walks independently of grid geometry. Every generator takes an explicit seeded RNG rather than relying on global state, closing a reproducibility gap in the original implementation.

DPO raises the target-zone score from 0.1298 to 0.1627, a ~25% relative gain, at a small cost to rule adherence (1.0000 → 0.9982). Rebuilt with seeded splits, a full test suite, and CI in place of the original's single notebook, which had never run cleanly end to end.
